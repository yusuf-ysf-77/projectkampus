# Plan: Build Dashboard & Sesi Halaman Website Penjadwalan

## Overview
Membangun seluruh halaman setelah login page (yang sudah ada di branch lain) sesuai sitemap:
**Dashboard → Jadwal → Tugas → Pengingat → Profil**

## Tech Stack
- Next.js 16 (App Router) + React 19
- shadcn/ui (radix-nova style) + Tailwind CSS v4
- React Hook Form + Zod (forms)
- lucide-react (icons)
- Mock data only (no backend)

## Step 1: Install Additional shadcn Components
Pasang komponen yang dibutuhkan:
```
npx shadcn@latest add card input label tabs dialog select separator badge avatar dropdown-menu tooltip table sheet
```

## Step 2: Layout & Navigation
Buat layout sidebar untuk semua halaman setelah login.

### Files:
- **`app/(dashboard)/layout.tsx`** — Sidebar layout dengan navigasi:
  - Dashboard (icon: LayoutDashboard)
  - Jadwal (icon: Calendar)
  - Tugas (icon: ClipboardList)
  - Pengingat (icon: Bell)
  - Profil (icon: User)
  - Logo/nama app di atas sidebar
  - User info + logout di bawah sidebar
- **`components/sidebar.tsx`** — Sidebar component (client component untuk active state)
- **`components/header.tsx`** — Top header bar (breadcrumb, user dropdown)

## Step 3: Dashboard Page
### Files:
- **`app/(dashboard)/page.tsx`** — Dashboard utama, menampilkan:
  - Ringkasan informasi dalam card:
    - **Jadwal Terdekat** — list 3-5 jadwal terdekat
    - **Tugas Belum Selesai** — count + list tugas pending
    - **Pengingat Aktif** — count + list pengingat aktif
  - Quick action buttons (Tambah Jadwal, Tambah Tugas, Tambah Pengingat)
- **`data/mock-data.ts`** — Semua mock data (jadwal, tugas, pengingat, user)

## Step 4: Jadwal Pages
### Files:
- **`app/(dashboard)/jadwal/page.tsx`** — Daftar Jadwal (tabel/card list)
  - Filter by tanggal/status
  - Tombol "Tambah Jadwal"
  - Setiap item bisa di-klik untuk edit
- **`app/(dashboard)/jadwal/tambah/page.tsx`** — Form Tambah Jadwal
  - Fields: Judul, Deskripsi, Tanggal, Waktu Mulai, Waktu Selesai, Kategori
- **`app/(dashboard)/jadwal/edit/[id]/page.tsx`** — Form Edit Jadwal
  - Same form as Tambah, pre-filled dengan data
- **`components/jadwal-form.tsx`** — Shared form component (Tambah/Edit)

## Step 5: Tugas Pages
### Files:
- **`app/(dashboard)/tugas/page.tsx`** — Daftar Tugas
  - Filter by status: Belum, Proses, Selesai
  - Badge warna untuk status
- **`app/(dashboard)/tugas/[id]/page.tsx`** — Detail Tugas
  - Info lengkap + tombol Update Status
- **`components/tugas-form.tsx`** — Form untuk create/edit tugas
- **`components/status-badge.tsx`** — Badge component untuk status tugas

## Step 6: Pengingat Pages
### Files:
- **`app/(dashboard)/pengingat/page.tsx`** — Daftar Pengingat
  - Toggle aktif/nonaktif
  - Tombol "Tambah Pengingat"
- **`app/(dashboard)/pengingat/tambah/page.tsx`** — Form Tambah Pengingat
  - Fields: Judul, Pesan, Waktu Pengingat, Pengulangan
- **`app/(dashboard)/pengingat/edit/[id]/page.tsx`** — Form Edit Pengingat
- **`components/pengingat-form.tsx`** — Shared form component

## Step 7: Profil Pages
### Files:
- **`app/(dashboard)/profil/page.tsx`** — Profil User
  - Data User (nama, email, foto)
  - Tombol "Ubah Password"
  - Tombol "Logout"
- **`app/(dashboard)/profil/ubah-password/page.tsx`** — Form Ubah Password
  - Fields: Password Lama, Password Baru, Konfirmasi Password

## Color Scheme
- Primary: Slate/Blue (#4F6D7A atau similar blue-grey) — clean & professional
- Dashboard accent: Blue
- Jadwal accent: Purple
- Tugas accent: Emerald/Green
- Pengingat accent: Orange/Amber
- Profil accent: Slate/Neutral
