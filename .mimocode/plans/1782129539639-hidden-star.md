# Rencana: Pindahkan Website ke Route /sketsa/

## Ringkasan
Memindahkan semua halaman dashboard (jadwal, tugas, pengingat, profil) ke bawah route `/sketsa/`. Landing page dan login tetap di root.

## Struktur Route Tujuan

```
/                          → Landing page (tetap)
/login                     → Login page (tetap, redirect ke /sketsa/dashboard)
/sketsa/dashboard          → Dashboard utama
/sketsa/jadwal             → List jadwal
/sketsa/jadwal/tambah      → Tambah jadwal
/sketsa/jadwal/edit/[id]   → Edit jadwal
/sketsa/tugas              → List tugas
/sketsa/tugas/tambah       → Tambah tugas
/sketsa/tugas/[id]         → Detail tugas
/sketsa/pengingat          → List pengingat
/sketsa/pengingat/tambah   → Tambah pengingat
/sketsa/pengingat/edit/[id] → Edit pengingat
/sketsa/profil             → Profil user
/sketsa/profil/ubah-password → Ubah password
```

## Langkah Implementasi

### 1. Buat folder `app/sketsa/` dengan layout
- Buat `app/sketsa/layout.tsx` (pindahkan content dari `app/(dashboard)/layout.tsx`)

### 2. Pindahkan halaman dashboard
- Pindahkan semua file dari `app/(dashboard)/` ke `app/sketsa/`:
  - `dashboard/page.tsx`
  - `jadwal/` (semua sub-route)
  - `tugas/` (semua sub-route)
  - `pengingat/` (semua sub-route)
  - `profil/` (semua sub-route)

### 3. Hapus folder lama
- Hapus `app/(dashboard)/` setelah pemindahan selesai

### 4. Update semua link dan redirect
- **Login page** (`app/login/page.tsx`): ubah redirect dari `/dashboard` ke `/sketsa/dashboard`
- **Sidebar** (`app/components/sidebar.tsx`): ubah semua nav links ke `/sketsa/*`
- **Header** (`app/components/header.tsx`): breadcrumb otomatis (tidak perlu ubah)
- **Halaman profil logout**: pastikan redirect ke `/` atau `/login`

### 5. Update metadata
- Judul app: "ScheduleApp" → "Sketsa" di `app/layout.tsx`

### 6. Verifikasi
- Jalankan `npm run build` untuk cek tidak ada error
- Jalankan `npm run dev` dan test semua route

## File yang Dimodifikasi

| File | Aksi |
|------|------|
| `app/sketsa/layout.tsx` | BUAT BARU (copy dari `(dashboard)/layout.tsx`) |
| `app/sketsa/dashboard/page.tsx` | PINDAH |
| `app/sketsa/jadwal/**` | PINDAH |
| `app/sketsa/tugas/**` | PINDAH |
| `app/sketsa/pengingat/**` | PINDAH |
| `app/sketsa/profil/**` | PINDAH |
| `app/(dashboard)/layout.tsx` | HAPUS |
| `app/(dashboard)/**` | HAPUS |
| `app/login/page.tsx` | EDIT redirect |
| `app/components/sidebar.tsx` | EDIT links |
| `app/layout.tsx` | EDIT metadata |

## Catatan
- Route group `(dashboard)` akan dihapus karena tidak diperlukan lagi
- Semua import path tetap sama karena menggunakan `@/*` alias
- `globals.css`, `components/ui/*`, `data/*`, `lib/*` tidak berubah
