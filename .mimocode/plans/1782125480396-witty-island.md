# Rencana: Landing Page + Login + Tema Biru-Abu-Putih

## Context
Website ScheduleApp sudah jadi (Dashboard, Jadwal, Tugas, Pengingat, Profil). Saat ini `app/page.tsx` langsung redirect ke `/dashboard`. User ingin:
1. Halaman awal (landing page) yang menjelaskan web + tombol Login
2. Halaman Login (form email+password, validasi basic, bisa input sembarang lalu redirect ke /dashboard)
3. Seluruh warna website diubah ke tema: abu-abu, putih, biru tegas
4. Sidebar: background putih, biru untuk active/highlight, abu-abu secukupnya

## Theme: Biru Tegas + Putih + Abu-Abu (Modern)

| Token | Value | Keterangan |
|---|---|---|
| `--primary` | `oklch(0.50 0.18 250)` | Biru tegas — tombol, aksen aktif |
| `--primary-foreground` | `oklch(0.99 0 0)` | Putih |
| `--background` | `oklch(0.98 0 0)` | Putih bersih |
| `--foreground` | `oklch(0.18 0 0)` | Abu gelap untuk teks |
| `--card` | `oklch(1 0 0)` | Putih |
| `--muted` | `oklch(0.96 0 0)` | Abu muda |
| `--muted-foreground` | `oklch(0.50 0 0)` | Abu sedang |
| `--border` | `oklch(0.91 0 0)` | Abu terang |
| `--sidebar` | `oklch(1 0 0)` | Putih (sidebar terang) |
| `--sidebar-primary` | `oklch(0.50 0.18 250)` | Biru aksen di sidebar |
| `--sidebar-accent` | `oklch(0.96 0 0)` | Abu muda untuk hover |
